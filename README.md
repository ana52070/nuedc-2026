# nuedc-2026

TI杯 2026 全国大学生电子设计竞赛 - 控制题

## 目录结构

```
nuedc-2026/
├── mcu/                    # 单片机代码
│   ├── stm32/              # STM32 版本
│   └── mspm0/              # TI MSPM0 版本
├── vision/                 # 视觉代码
│   ├── rk3588/             # RK3588 方案
│   ├── k230/               # K230 方案
│   └── opencv/             # OpenCV 备用方案
└── 竞赛报告/               # 设计报告相关素材
```

## 提交规范

格式：`[组别] 做了什么`

示例：
- `[电控] 添加JY60驱动`
- `[视觉] rknn推理调通`

大文件（模型文件 .rknn/.kmodel 等）请走网盘，不上传 Git。
